# Agent Skills

This document describes how agent skills are configured for this repository.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Default triage label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout with central architecture docs in `teamtools_documentation` and repo-specific context here. See `docs/agents/domain.md`.
